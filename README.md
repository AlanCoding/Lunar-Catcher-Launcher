# Lunar Catcher / Launcher Studies

This repository contains two related research topics:

| Topic | Files and purpose |
| --- | --- |
| [Lunar slings](lunar_slings/README.md) | Original surface-launch / orbital-catcher notebook, downrange plots, and a dedicated sling analysis workspace. |
| [Frozen retreat](frozen_retreat/README.md) | Scenario-based study of a 30 km catcher, retreat to 120 km, electric propulsion, and transfer to a staging orbit. |

Each topic keeps its own dependencies and run instructions. The original notebook and its two plots now live together in `lunar_slings/`; the `frozen_retreat/` paths are unchanged.

Start with the [initial lunar sling assessment](lunar_slings/analysis/README.md) for the existing model's results, limitations, and work needed for a rotating sling study.
